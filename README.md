# coc

基于构造演算（Calculus of Constructions）的极简定理证明器。

## 开始使用

克隆本项目：

```sh
git clone https://github.com/SilencerHH/coc.git
cd coc
```

安装 [SML/NJ](https://www.smlnj.org/) 并进入交互环境：

```sh
sml
```

编译 → 导入交互函数 → 加载库：

```sml
CM.make "coc.cm"; open Main; init ();
```

接下来就可以开始交互式定理证明了。

## 交互

- `check "example";` 检查文件 `example` 的正确性。如果文件存在问题，修改文件并再次尝试 `check`，循环往复直到问题解决。
- `commit ();` 提交刚刚检查成功的文件，以便继续检查其他文件。除非环境重置，已提交的文件不能重复检查，否则系统可能会困惑于再次看到已经提交的定义并报错。
- `load "example";` 一步完成 `check` 和 `commit`。
- `reset ();` 重置环境，清空所有提交过的文件（包括库）。
- `axioms ();` 展示已检查的所有文件中的公理列表。
- `init ();` 重置环境并加载库，顺便展示库公理列表。

试着输入 `check "example";`，看看会输出什么，问题又该如何解决。

## 语法

井号 `#` 开启行注释。变量可以是大小写字母、数字、下划线或 `+-*/<=>\~` 这些符号的任意组合。

```
p ::= {c}                                # 每个文件由多条命令组成。
c ::= "axiom" x ":" t                    # 每条命令可以声明一个公理（名称与类型）
    | "def" x [":" t] ":=" t             # 或一个定义（名称、可选的类型与定义体）。
t ::= "prop"                             # 一个项可以是 prop（类型的类型）、
    | x                                  # 变量、
    | "{" x ":" t "}" t                  # 函数类型、
    | t "->" t                           # （箭头类型是函数类型的缩写）
    | "[" x [":" t] "]" t                # 函数（能推导出的参数类型可以省略）、
    | t "(" t "," ... "," t ")"          # 函数调用、
    | t x t                              # （中缀形式的函数调用（右结合），
    | t x "@" t t                        # 可以携带一个
    | t x "@" "(" t "," ... "," t ")" t  # 或多个参数）
    | "let" x [":" t] ":=" t "in" t      # let 绑定、
    | "?"                                # 洞、或者
    | "(" t ")"                          # 用括号括起的另一个项（用于调整优先级）。
```
